# Ginomai 2.4.3

## Software Updates

- Quiet update indicators and a compact update panel show check, download, cancellation, and restart progress.
- Downloads require an explicit action by default. Automatic background downloads can be enabled in Settings and the preference persists across restarts.
- Downloading an update never installs it automatically on app exit. Restart to Update remains an explicit action.
- Restart checks protect active sermon recording, AI microphone capture, and connected projector, stage, and livestream outputs. The workspace is saved before installation.
- What's new displays readable release notes inside the update panel, with cached notes available offline.
- Update actions are restricted to the host desktop window. Remote operators and output windows cannot install updates.

## Workspace

- The desktop workspace now uses Bento throughout. Saved Classic preferences migrate to Bento while preserving light or dark mode.
- Bible, song, and AI detection controls use the current Bento interface, with updated preview and slide-card styling.

## Updating

Windows x64 installations with the Ginomai GitHub update feed can use Help > Check for Updates, download 2.4.3, and choose Restart to Update after the service is finished.

Older builds without an update feed need a one-time installation of the native Windows installer from this release. Refresh remote operator pages after updating the host. This release contains Windows x64 artifacts.

This Windows installer is unsigned, as in the previous release. Manual installation may display a Windows SmartScreen warning.

## Validation

The desktop test suite passed: 384 tests passed, two skipped, and no failures.

Update-panel and host/operator browser checks passed. The packaged Windows runtime passed checks for explicit downloads, saved preferences, host-only updater access, workspace saving, and restart protection during recording, microphone use, and connected output activity. Installation was simulated in the packaged runtime test.
