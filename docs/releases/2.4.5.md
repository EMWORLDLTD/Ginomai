# Ginomai 2.4.5

## Bible Imports and Search

- Added support for numbered Scripture XML Bible files, including Unicode translation names and verse text.
- Strong’s Concordance searches run in a background worker. Rapid typing, language changes and leaving the search view discard outdated results.
- Improved semantic model integrity checks to accept unchanged JSON files with Windows line endings.

## Sermon History

- AI and recording activity use one sermon session per local day, without creating empty sessions while the app is idle.
- Recordings crossing midnight preserve the previous day’s pending words and continue into the new day.
- Improved archived-session handling, deletion, restored recording state and timestamped exports.

## Library and Device Storage

- Added controls for clearing selected downloaded content, imported libraries and uploaded media.
- Library cleanup waits for database changes to finish and retains the bundled KJV Bible.
- Improved migration folder selection through the desktop folder picker.
- Windows uninstall offers an optional saved-data and downloads cleanup; normal upgrades retain application data.

## Projection and Packaging

- Improved announcement synchronization with resident output previews.
- Desktop packages include the application runtime and target-specific AI binaries while excluding development files and redundant dependencies.
- KJV and PDF assets remain bundled. Other Bible translations, Strong’s content and semantic AI assets use the separate content-pack downloads.

## Updating

Windows x64 users can open Help > Check for Updates, download 2.4.5 and choose Restart to Update after the service is finished. Refresh remote operator pages after updating the host.

For manual installation, download `Ginomai-Setup-2.4.5-win-x64.exe` or the native `Ginomai-2.4.5-native-x64.exe` installer from this release.

Older builds without an update feed need a one-time manual installation of the native installer. The Windows installers are unsigned, as in the previous release; Windows may display a SmartScreen warning.

## Validation

Focused release checks passed: 191 tests passed and three fixture/platform checks were skipped. The offline AI smoke check passed on an isolated retry after timing out during parallel validation.

Headless browser checks passed for explicit update actions, dismissal click protection, keyboard focus, download progress, activity guards and Classic/Bento light and dark themes. Syntax checks passed for the changed JavaScript runtime files.

The packaged Windows updater smoke test passed for explicit downloads, persisted preferences, recording/microphone/output restart guards, host-only controls and workspace saving. The update transport and installation step were simulated.
