# Ginomai 2.4.4

## Video Deck

- A four-slot video deck supports preparing and controlling service videos.
- Each service session saves its own deck. Restored decks keep video settings while clearing transient preview playback and audio state.
- Updated presentation controls, library, and output handling support the video deck.

## Desktop and Displays

- A custom desktop title bar provides menus and window controls.
- Sanctuary projection targets an external display and cannot be redirected onto the laptop by an outdated saved preference.
- Stage and sanctuary outputs use separate displays. With one external display, sanctuary uses that screen and stage uses the laptop.
- Display routing preserves connection order across operating-system enumeration changes and handles unplugging and reconnecting screens.
- Update indicators appear only while an update is pending.

## Updating

Windows x64 users can open Help > Check for Updates, download 2.4.4, and choose Restart to Update after the service is finished. Refresh remote operator pages after updating the host.

Older builds without an update feed need a one-time installation of the native Windows installer. This Windows installer is unsigned, as in the previous release; manual installation may display a Windows SmartScreen warning.

## Validation

The desktop test suite passed: 398 tests passed, two skipped, and no failures. Headless browser checks passed for update controls, the video deck, and host/operator navigation and controls.
