# Ginomai 2.4.2

## Operator Console

- Remote operators use the host's slide-selection flow. Projection echoes no longer rebuild the chapter or song deck, reset its scroll position, or send redundant workspace patches.
- Verse and song navigation updates the preview immediately. Late host snapshots cannot replace a newer pending operator selection.
- Operators can start and stop the host AI engine, start and stop sermon recording, view the host sermon transcript, and hold or release live output.
- Microphone capture and device selection remain on the host computer.
- Pairing inputs are aligned and sized consistently on smaller screens.

## Interface and Output

- Compact toolbar layouts improve the dashboard on smaller laptop screens.
- Resize-handle instruction tooltips have been removed.
- Software Migration content and detection summaries are readable in light mode.
- Livestream output defaults to Bottom overlay unless Full screen was explicitly selected.
- Text-only bottom overlays support an optional full-width background fade with adjustable strength.

## Updating

Windows x64 installations with the Ginomai GitHub update feed can use Help > Check for Updates. Restart Ginomai to install the downloaded update, refresh the remote operator dashboard, and pair it again if prompted.

Older builds without an update feed need a one-time installation of the native Windows installer from this release. No macOS artifacts are included in this Windows release.

This Windows build is unsigned. Manual installation may display a Windows SmartScreen warning; a code-signing certificate was not available for this release.

## Validation

Host/operator round-trip browser tests cover verse and song navigation, rapid clicks, preview consistency, AI start/stop, sermon recording and transcript mirroring, Hold live, and microphone-selection restrictions. Release artifacts and updater metadata are checked before publication.
